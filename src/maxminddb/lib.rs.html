2//! # MaxMind DB Reader
3//!
4//! This library reads the MaxMind DB format, including the GeoIP2 and GeoLite2 databases.
5//!
6//! ## Features
7//!
8//! This crate provides several optional features for performance and functionality:
9//!
10//! - **`mmap`** (default: disabled): Enable memory-mapped file access for
11//!   better performance in long-running applications
12//! - **`unsafe-str-decode`** (default: disabled): Skip UTF-8 validation
13//!   when deserializing trusted database strings into Rust `str` or `String`
14//!   values. Cross-runtime format adapters should prefer
15//!   [`deserialize_any_with_raw_strings()`] and validate while constructing
16//!   the target runtime's string type.
17//!
18//! ## Database Compatibility
19//!
20//! This library supports all MaxMind DB format databases:
21//! - **GeoIP2** databases (City, Country, Enterprise, ISP, etc.)
22//! - **GeoLite2** databases (free versions)
23//! - Custom MaxMind DB format databases
24//!
25//! ## Thread Safety
26//!
27//! `Reader<S>` is `Send` when `S` is `Send`, and `Sync` when `S` is `Sync`.
28//! `Reader<Vec<u8>>`, returned by [`Reader::open_readfile`], implements both:
29//!
30//! ```
31//! fn assert_send_sync<T: Send + Sync>() {}
32//! assert_send_sync::<maxminddb::Reader<Vec<u8>>>();
33//! ```
34//!
35//! Custom sources passed to [`Reader::from_source`] determine these traits.
36//! For example, a source of type `std::rc::Rc<[u8]>` makes the reader neither
37//! `Send` nor `Sync`.
38//!
39//! ## Quick Start
40//!
41//! ```rust
42//! use maxminddb::{Reader, geoip2};
43//! use std::net::IpAddr;
44//!
45//! fn main() -> Result<(), Box<dyn std::error::Error>> {
46//!     // Open database file
47//! #   let reader = Reader::open_readfile("test-data/test-data/GeoIP2-City-Test.mmdb")?;
48//! #   /*
49//!     let reader = Reader::open_readfile("/path/to/GeoIP2-City.mmdb")?;
50//! #   */
51//!
52//!     // Look up an IP address
53//!     let ip: IpAddr = "89.160.20.128".parse()?;
54//!     let result = reader.lookup(ip)?;
55//!
56//!     if let Some(city) = result.decode::<geoip2::City>()? {
57//!         // Access nested structs directly - no Option unwrapping needed
58//!         println!("Country: {}", city.country.iso_code.unwrap_or("Unknown"));
59//!     }
60//!
61//!     Ok(())
62//! }
63//! ```
64//!
65//! ## Selective Field Access
66//!
67//! Use `decode_path` to extract specific fields without deserializing the entire record:
68//!
69//! ```rust
70//! use maxminddb::{path, Reader};
71//! use std::net::IpAddr;
72//!
73//! let reader = Reader::open_readfile("test-data/test-data/GeoIP2-City-Test.mmdb").unwrap();
74//! let ip: IpAddr = "89.160.20.128".parse().unwrap();
75//!
76//! let result = reader.lookup(ip).unwrap();
77//! let country_code: Option<String> = result.decode_path(&path!["country", "iso_code"]).unwrap();
78//!
79//! println!("Country: {:?}", country_code);
80//! ```

101/// Internal entry points for the cargo-fuzz targets.
102#[cfg(feature = "fuzzing")]
103#[doc(hidden)]
104pub mod fuzzing {
105    use serde::Deserialize;
106
107    use crate::decoder::{Decoder, VerificationState};
108    use crate::MaxMindDbError;
109
110    /// Deserialize one data-section value through the Serde decoder.
111    pub fn decode<'de, T>(data: &'de [u8]) -> Result<T, MaxMindDbError>
112    where
113        T: Deserialize<'de>,
114    {
115        T::deserialize(&mut Decoder::new(data, 0)).map_err(Into::into)
116    }
117
118    /// Validate one data-section value through the verification decoder.
119    pub fn verify(data: &[u8]) -> Result<(), MaxMindDbError> {
120        Decoder::new(data, 0)
121            .skip_value_for_verification(&mut VerificationState::new(data.len()))
122            .map_err(Into::into)
123    }
124}
